# مطبعة الأداء اليسير — تطبيق الويب فائق الدقة

تطبيق ويب عربي فائق الدقة والأناقة (RTL) مبني بأحدث التقنيات وفق قاعدة **"صفر حشو — توازن هندسي صارم (Strict Grid & Whitespace Balance)"** لمطبعة **الأداء اليسير**.

## الميزات المعمارية والتقنية:
- **هيكل الصفحات (Google Ads Sitelinks Ready)**:
  - `/` — الرئيسية
  - `/services` — خدماتنا (7 خدمات بكتل متوازنة وروابط واتساب مباشرة)
  - `/products` — المنتجات (16 منتجاً مع فلاتر وبحث فوري ونموذج طلب تسعيرة)
  - `/about` — من نحن (المعدات والخطوط والقدرات الإنتاجية)
  - `/partners` — شركاؤنا (قائمة الشركاء ومعرض صور المشروعات المنجزة)
  - `/reviews` — آراء العملاء (تقييمات موثقة 4.9/5)
  - `/contact` — تواصل معنا (نموذج تفصيلي، موقع خرائط جوجل، ورقم الهاتف)
- **أيقونات التفاعل العائمة فقط (Zero Text / Zero Bottom Bar)**:
  - زر واتساب عائم دائري أخضر (`#25D366`) عند `bottom-5 left-5`
  - زر خرائط جوجل عائم دائري كحلي (`#0A1128`) عند `bottom-5 left-5`
- **توازن هندسي صارم**:
  - خطوط عربية راقية: **IBM Plex Sans Arabic** و **Cairo**
  - ألوان محددة: الكحلي الداكن (`#0A1128`)، الأزرق الملكي (`#2563EB`)، الأخضر (`#25D366`)، والرمادي الناعم (`#F8FAFC`).
  - العناوين من كلمتين إلى 3 كلمات فقط، والنصوص لا تتجاوز سطراً واحداً دون أي حشو.

## التشغيل والتطوير:
```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء الإنتاج
npm run build

# معاينة البناء
npm run preview
```
